## Problem Statement

Web applications are increasingly targeted by cyberattacks such as SQL Injection, Cross-Site Scripting (XSS), CSRF, Command Injection, and File Inclusion attacks. Traditional Web Application Firewalls (WAFs) often require significant technical expertise to configure and manage, making them inaccessible to small organizations, students, or non-technical users. There is a need for a lightweight, user-friendly WAF that allows users to create and manage custom rules, detect real-time attacks, and visualize threat activity—without requiring deep cybersecurity knowledge. This project aims to bridge that gap by developing an intuitive WAF with dynamic rule creation, automated protection mechanisms, and interactive analytics.

---

## Abstract

This project presents a lightweight yet powerful **Web Application Firewall (WAF)** designed to protect modern web applications from common cyber threats such as SQL Injection, XSS, CSRF, LFI/RFI, and Command Injection. Unlike traditional WAFs that require technical expertise, this system introduces an intuitive **Custom Rule Builder** that allows even non-technical users to create, modify, and deploy security rules effortlessly. The WAF integrates real-time detection, dynamic rule matching, detailed logging, and visual analytics through an interactive dashboard. It provides instant alerts, attack summaries, auto-refreshing logs, and traffic insights using bar and pie charts. The solution is built with Flask, SQLAlchemy, Bootstrap, and JavaScript, making it lightweight, extensible, and suitable for both academic and practical deployments. Overall, the system empowers users with an accessible and effective layer of web application defense.
